# Спрайтовая мимика персонажей

Спрайтовая мимика позволяет менять выражение лица на анимированном 3D-меше. На модели задаётся область лица, а внутри неё — независимые зоны, например левый глаз, правый глаз, брови и рот. У каждой зоны свой список спрайтов. Один персонаж может закрыть глаз, пока другой экземпляр той же модели сохраняет исходное выражение.

## Настройка в Blender

1. Открой **N → Vecxy → Character**. Выбери коллекцию персонажа или создай её из рига либо меша через **Create from Selection**. В **Animations** добавь Actions и задай имена клипов для игры.
2. В **Face Sprites** укажи **Face Mesh**. В Edit Mode выдели грани лица, выбери плоскость **Projection** и нажми **Assign Selected Polygons**. Контур в Blender проходит по границе выбранных граней.
3. Добавь зоны и задай им ID, которые будут использоваться в игре, например `eyes` и `mouth`. В Object Mode нажми **Edit Zones in Viewport**. Зоны можно двигать и растягивать мышью. Shift-клик добавляет зону к выделению, **H** скрывает подсветку, **Enter** подтверждает изменения.
4. Через **Add Sprite Image** добавь отдельную картинку. Для PNG-атласа используй **Project Face Library → Import Atlas → Choose Atlas → Add from Atlas**. Выдели область мышью. С Shift можно выделить ещё несколько областей за один сеанс. **Enter** сохраняет вырезки. **Save Sprite** добавляет выбранный спрайт в библиотеку проекта, **Use Saved Sprite** применяет его в другой зоне. Библиотека хранится в `Authoring/FaceSpriteLibrary.json`.
5. Назначь ID спрайтов, например `open`, `closed` и `smile`. **Show in Preview** переключает спрайт во вьюпорте, **Set as Default** задаёт стартовое выражение в игре. Прозрачность PNG сохраняет видимым материал лица под спрайтом. **Pixel filtering** использует фильтрацию по ближайшему пикселю.
6. Выполни **Check Before Export**, затем **Export Character** в папку внутри `Assets`. Для примера ниже выбери `Assets/Characters/Hero.glb`.

Экспорт создаёт `Hero.glb` с моделью, ригом и клипами, `Hero.character.prototype` с настройками персонажа и `Hero.face.prototype` с зонами и ссылками на изображения. Для атласа сохраняются путь к PNG относительно `Assets` и прямоугольник вырезки в пикселях. При переносе персонажа сохрани относительные пути к PNG и экспортированным файлам.

## Управление из C#

```csharp
using Vecxy.Animations;
using Vecxy.Prototypes;
using Vecxy.Scene;

var hero = prototypes.Instantiate<Character>(
    "Characters/Hero.character.prototype",
    new ScenePrototypeContext { Scene = scene, Position = spawnPosition });

hero.Play("walk");

if (hero.Face is { } face)
{
    face.SetSprite("eyes", "closed");
    face.SetSprite("mouth", "smile");

    var availableMouthSprites = face.GetSpriteIds("mouth");
    var currentMouthSprite = face.GetSprite("mouth");

    // Скрыть спрайт зоны или вернуть стартовый.
    face.SetSprite("mouth", null);
    face.SetSprite("eyes", face.GetDefaultSprite("eyes"));
}
```

`Zones` перечисляет ID зон. `GetSpriteIds(zoneId)` возвращает список вариантов для зоны, `GetSprite(zoneId)` — текущий ID или `null` для скрытой зоны, `GetDefaultSprite(zoneId)` — стартовый ID или `null`. Имена чувствительны к регистру. Неизвестный ID зоны или спрайта при обращении к нему вызывает `KeyNotFoundException`.

Для моргания переключи глаза на `closed` и верни прежний спрайт по таймеру. Для речи вызывай `SetSprite` с очередной формой рта из игровой логики или обработчика события анимации. Смена спрайтов и проигрывание скелетных клипов управляются отдельно.

## Данные и отрисовка

`_VECXY_FACE_UV` задаёт отдельные координаты лица на выбранных гранях. Обычная UV-развёртка продолжает использоваться для материала модели. Прямоугольники зон задаются в диапазоне 0–1 с началом в левом верхнем углу области лица. Для вырезок `spriteRegions` начало координат находится в левом верхнем углу исходного PNG.

Компонент `Vecxy.Rendering.FaceSprites` собирает текущие спрайты в текстуру экземпляра при изменениях. Стандартный Lit-шейдер накладывает её на цвет материала по координатам лица. Эти координаты остаются на меше при скелетной деформации. Кроме загрузки через `Character`, компонент можно настроить вызовом `FaceSprites.Configure` на меше с координатами лица. Для статического меша вне коллекции персонажа аддон также экспортирует мимику через обычный USD-экспорт сцены.
