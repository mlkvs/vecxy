# Навигация

`Vecxy.AI` запекает карту проходимости уровня и ведёт агентов к заданным точкам. Первая версия хранит одну высоту пола на ячейку и использует A* с проверкой зазора у углов. Есть поддержка пандусов и ступеней для одного профиля агента на сцену.

## Blender 5.2 и новее

1. Открой **N → Vecxy → AI → Navigation**. **Entire Scene** автоматически охватывает все статичные коллайдеры сцены. Для отдельной зоны выбери **Area Box → Create Box → Edit Area in Viewport** и потяни за ручку нужной грани. Противоположная грань останется на месте. **Enter** применяет изменения, **Esc** отменяет. **Fit to Scene** снова растянет бокс на всю сцену.
   Радиус и высота бота находятся в **Bot Size**. Размер ячейки, допустимый уклон и высота ступени находятся в **Bake Settings**. Одна единица Blender соответствует метру.
2. Разметь пол и стены обычными статичными коллайдерами. Триггеры пропускаются. Box Collider задаёт геометрию коробки, Mesh Collider использует треугольники, Sphere и Capsule учитываются консервативно по объёму.
3. Для двери или ящика добавь **AI / Navigation Obstacle** через обычный список **Components**. **Use Object Colliders** привязывает навигацию к коллайдерам объекта и его дочерних объектов. Отключи галочку, если нужен отдельный объём только для навигации. **Edit Box in Viewport** включает ручки на его гранях. **Box Offset** и **Box Dimensions** позволяют точно задать положение относительно объекта и размеры. В игре положение препятствия обновляется при перемещении объекта. Компонент можно назначить исходному Shared Prototype или экземпляру.
4. Через **Add Blocker** поставь полупрозрачный объём в позиции 3D Cursor. Щелчок внутри его видимой грани выделяет блокер. Для редактирования включи **Edit Blocker in Viewport** или используй обычные инструменты Blender. Блокеры влияют на маршруты ботов.
5. Сохрани сцену и нажми **Bake / Rebuild Navigation**. Аддон сам находит установленный npm CLI `vecxy` и вызывает его из папки проекта. Готовая карта появится рядом с USD, например `Assets/Scenes/Main.navigation.json`.
6. Включи **Show Baked Navigation**. Зелёным показана проходимая поверхность, красным — ячейки, которые подвижные препятствия перекрывали в момент запекания. Фиолетовые объёмы показывают ручные блокеры. После перемещения блокеров или правок статичных коллайдеров снова нажми **Bake / Rebuild Navigation**. Динамические препятствия попадают в игру при обычном экспорте USD.

## C#

Сервис `INavigation` доступен из стандартного `EngineLayer`. Создай или загрузи объекты уровня до вызова `Load` или `Bake`. Запечённые из Blender карты используют мировые координаты уровня в движке, поэтому загружай их для уровня в исходном положении.

```csharp
using System.Numerics;
using Vecxy.AI;
using Vecxy.Pathfinding;

navigation.Bake(scene, new NavigationBakeSettings
{
    Min = new Vector3(-8, -.5f, -8),
    Max = new Vector3(8, 4, 8),
    CellSize = .2f,
    Radius = .3f,
    Height = 1.8f
});

var agent = bot.AddComponent(new NavigationAgent { Speed = 1.8f });
agent.SetDestination(new Vector3(4, 0, 2));

door.AddComponent<NavigationObstacle>();

var blocker = scene.CreateObject("Bot-only boundary");
blocker.Transform.WorldPosition = new Vector3(2, 1, 0);
blocker.Transform.Scale = new Vector3(1, 2, 3);
blocker.AddComponent<NavigationBlocker>();

navigation.DebugDraw = true;
```

Для готового уровня из Blender загрузи его карту вызовом `navigation.Load(scene, "Scenes/Main.navigation.json")` вместо вызова `Bake`.

Агент использует позицию объекта как положение ног. `SetDestination` принимает точку в мире. Если ячейка цели заблокирована или прохода до неё нет, `State` будет `NoPath`. При освобождении пути агент попробует снова. `Path` и `NextWaypoint` дают доступ к текущему маршруту, `Stop()` отменяет движение. Для запроса маршрута без агента используй `navigation.GetMap(scene)?.FindPath(from, to)`.

Препятствия с `NavigationObstacle` учитываются отдельно от статической карты. Когда дверь открывается, освобождаются перекрытые ею ячейки. Если новый объём пересёк оставшуюся часть маршрута, агент перестроит его. Блокеры из Blender запекаются в карту. Блокеры из кода можно включать, отключать и перемещать во время игры.

`navigation.Capture(scene, settings)` собирает данные из коллайдеров. `NavigationBaker.Bake(input)` запекает их без зависимости от сцены и графического контекста. Результат можно передать в `navigation.SetMap(scene, data)` или сохранить через `NavigationData.Write(stream)`. Для вызова того же запекателя из инструментов есть `vecxy navigation bake <input.json> --output <map.navigation.json>`.

## Отладка

`DebugDraw` выключен по умолчанию. Его можно включить при создании движка через `new EngineLayer.Definition(navigation: new NavigationModule.Options { DebugDraw = true })` или в любой момент через `INavigation.DebugDraw`.

- Зелёные точки и линии показывают проходимую поверхность и её границы.
- Красные контуры показывают объёмы препятствий. Красные отметки на полу показывают ячейки, которые в данный момент закрыты динамическими препятствиями.
- Голубым показаны габариты агента, маршрут, следующая точка и цель. Контур агента красный при `NoPath` и жёлтый после прибытия.

В текущей версии агент перемещает объект по карте. Для нескольких независимых этажей в одной вертикальной колонке и для физического управления динамическим телом понадобится отдельная реализация.
